# Definition of Done

## Artifact

- [ ] Public or evaluator-accessible deployed app URL works.
- [ ] Public/evaluator-accessible source repository works.
- [ ] Home accepts a topic.
- [ ] Live OpenAIRE path returns data.
- [ ] Four count classes render.
- [ ] Potential gap/no-gap state is deterministic.
- [ ] “Why” renders at most three evidence-based reasons.
- [ ] Evidence records are inspectable.
- [ ] Provider errors do not fabricate findings.
- [ ] Mobile layout is readable.
- [ ] Production build passes.
- [ ] P0 tests pass.

## Methodology

- [ ] Heuristic documented.
- [ ] Limitations documented.
- [ ] Retrieval timestamp/methodology version present in result or export.
- [ ] Demo fixture, if retained, is visibly labelled.

## Submission

- [ ] 1–2 page story completed.
- [ ] Question/journey/insight/reuse all covered.
- [ ] Theme selected.
- [ ] License statement present.
- [ ] Screenshots captured.
- [ ] Demo script rehearsable in <=3 minutes.
- [ ] Final form answers prepared.
- [ ] Repository README complete.
- [ ] Submission completed before internal cutoff.
- [ ] Submission confirmation retained.
