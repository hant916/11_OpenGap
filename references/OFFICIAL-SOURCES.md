Checked 19 Aug 2026.

## OpenAIRE AI Hackathon

https://innovation.openaire.eu/component/content/article/openaire-ai-hackathon.html?catid=8

Relevant official constraints:

- submission deadline: 20 Aug 2026, 23:59 CET;
- participants use OpenAIRE Graph, including via OpenAIRE MCP plugged into Alien's AI Gateway;
- Theme B: build a tool/app/agent/workflow/integration that makes the Graph more useful;
- Theme C explicitly mentions evidence, field mapping, funding flows, gap identification and benchmarking;
- submission model is “artifact + story”;
- story is 1–2 pages covering question, journey, insight and reuse;
- materials are expected under CC-BY.

## OpenAIRE Graph API V3 overview

https://graph.openaire.eu/docs/apis/graph-api/overview/

V3 is the current recommended stable API and exposes research products, projects, organizations, data sources and persons.

## Research Products V3

https://graph.openaire.eu/docs/apis/graph-api/research-products/

Important MVP property: response header contains `numFound`, while `results` provides the records. This allows counts + a few evidence items without full paging.
