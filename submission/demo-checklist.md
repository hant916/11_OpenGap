# Demo Checklist

## Before recording/live demo

- [ ] Golden topic selected from real live results.
- [ ] Numbers manually spot-checked against OpenAIRE response.
- [ ] At least two evidence links open correctly.
- [ ] Loading state looks clean.
- [ ] Provider failure state tested.
- [ ] Mobile/desktop width acceptable.
- [ ] Browser console free of obvious errors.
- [ ] No API secret visible client-side.
- [ ] App opened from deployment URL in private/incognito window.
- [ ] Story numbers match the current demo or avoid hard-coding unstable counts.

## Backup

- [ ] Screenshot of successful result.
- [ ] Short screen recording if time permits.
- [ ] Do not present fixture metrics as live OpenAIRE data.
